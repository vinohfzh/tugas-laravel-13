## overview

Aplikasi web untuk mengelola tugas sekolah secara digital, dibangun di atas **Laravel 13** sebagai bagian dari praktikum *AI Native Framework*. Mencakup manajemen tugas, sistem autentikasi guru & siswa, serta dashboard monitoring berbasis PHP 8.3+.

## stack

| layer | teknologi |
|---|---|
| backend | Laravel 13 |
| language | PHP 8.3+ |
| database | MySQL |
| frontend | Blade + Vite |
| auth | Laravel Breeze |

## getting started

bash
# clone & masuk folder
git clone https://github.com/username/tugas-sekolah.git
cd tugas-sekolah

# install dependencies
composer install && npm install

# setup environment
cp .env.example .env
php artisan key:generate

# migrasi database
php artisan migrate --seed

# jalankan
php artisan serve


Akses di `http://localhost:8000`
